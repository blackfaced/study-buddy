# 规范书写评分

练字应用使用浏览器内的 `handwriting-coach` 作为唯一判定入口。孩子提交的每一笔都保留原始点序列；HanziWriter 的 `medians` 提供有顺序、有方向的结构化参考。自然语言只负责向孩子解释结果，不参与笔顺判定。

## 规则

- 方格位置不做整字平移归一化。中心偏移不超过方格边长的 3% 视为自然波动，3%–8% 为轻微偏移，8%–15% 为明显偏移，超过 15% 要再写一次。
- 高置信度的倒笔画或先写后笔会在抬笔后立即撤销。无法可靠判断时保留该笔并标记为“不确定”，不把系统疑问算成孩子错误。
- 同一笔连续出错时，提示依次升级为预期位置、起点和方向、笔画动画。
- 发生笔顺或方向纠正后，孩子需要在空白方格独立重写一次；第二次仍有问题时记录为稍后复习，不循环拦截。
- 整字内部按结构与比例 30%、方格位置 25%、单笔几何 25%、整体形状 20% 计算 0–100 内部分数。孩子只看到“需要再观察 / 基本正确 / 写得规范 / 写得很好”和最多两条原因。
- 缺少参考数据时显示“暂时无法判断”，不生成低分。

## 合法笔顺变体

变体用笔画索引排列记录在 `VALIDATED_STROKE_ORDERS`，例如两笔字的反向合法顺序写成 `[[1, 0]]`。只有经过成人对照权威资料确认的变体才可加入；不要写自然语言规则，也不要通过降低全局阈值放行。

## 视觉复评

本地规则是主判定。只有结构置信度不足或分档临界时，客户端才异步上传当前单字的裁剪图，请视觉模型补充一句结构建议。视觉模型不能更改笔顺、方向、完整性、方格位置或本地档位；超时、未配置和调用失败都不阻塞练字。

## 数据与部署

`writing_attempts` 同时保存原始笔画、逐笔判定过程、分项结果、原因、算法版本和可选的视觉复评元数据。数据库迁移后需要重启 HTTP server；若 mcp-server 后续读取这些字段，也要一并重启其宿主进程。
