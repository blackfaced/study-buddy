# 错题与纸质练习为主，应用辅助

2026-09-06 的产品方向，关联 [#192](https://github.com/blackfaced/study-buddy/issues/192)。修改选题、游戏轮次和统计、写字、打印、反馈或对应 issue 时，以本文为准。以下是目标行为；已有网页默写、练字评分和固定日期复习代码并不代表这些目标已经实现。

## 主路径

学校作业、试卷和确认过的错题 → 少量本次练习 → 可审阅的打印草稿 → 固定版本的孩子版 → 纸上作答 → 有空时确认部分结果 → 调整下一份。

- 上传或登记资料不产生做题事实；明确处理后先形成候选，确认的真实错误才进入 Capture。
- 空白卷、题库内容、家长关注点、历史错误和近期确认的作答分别表达。关注点可以引导基础检查，不自动等同于已证实的薄弱项。
- 本次选择有题量上限。历史开放 Correction Obligation 保留，但不直接变成今天必须清空的作业清单。
- 零应用记录、跳过一周、上份练习没有反馈，都允许继续。未知不记成错误、正确或退步；缺席不增加后续任务量。
- 第一份以一张 A4 为范围起点，可以更少。证据不足时说明依据有限，使用家长选定的学校内容或基础检查，不为凑时长和证据比例制造题目。
- 学校必做内容与系统额外补充分别呈现；额外补充可以减为零，学校范围不被静默删减。

## 游戏：每天一轮，首轮表现与订正分开

当前启用的游戏，使用日各做一轮，以完成本轮并把错误改对为目标。它是短时辅助，不是纸质练习的前置条件。未使用日记为未练；新增游戏不自动增加家庭练习量。

家长需要看到：

| 信息 | 含义 |
|---|---|
| 首轮正确率 | 首次答对题数 / 已首次作答题数，同时显示已答题数 / 本轮题数。未完成和零作答不会显示为“全对”。 |
| 首轮用时 | 从开始到完成首次作答的练习时间；暂停、后台时间单独处理，不把长时间离开当成做题慢。 |
| 订正用时和重试 | 首轮之后额外花了多久、哪些题重试了；不覆盖首轮答案或时间。 |
| 本轮状态 | 未开始、进行中、已完成；中断可以恢复。“全对”要求本轮题目均有有效作答且本轮错误已改对。 |

例如：10 题首次答对 8 题，之后全部改对，仍保留“首轮 8/10、本轮已订正完成”，而不是只剩 100%。有提示、重试后的正确与首次独立正确分别记录；游戏完成不自动等于稳定掌握。

统计供家长查看，孩子端保持无分数、排名、连胜、可见计时器和掌握百分比。暂停、离开和未完成是可恢复状态，不要求孩子无限循环到全对才能退出。

重试范围采用待核对的首版建议：只重做本轮错题，已正确题目不再重复。若家庭选择整轮重做，则每次重做仍保留为同一 Practice Round 的后续尝试，首轮统计不变。实现前必须确定此选择，不把两个模式都预建出来。

## 写字：笔顺和结构示范

孩子或家长找一个字 → 查看笔画顺序与字结构 → 在纸上书写，需要时再看示范。

- 主要能力是找字、逐笔/重播演示和结构展示；近期错字与纸质观察可以帮助定位要看的字。
- 网页默写、必须在屏幕上书写、自动字迹评分和候选队列清零退出首版主流程。相关既有内容是兼容资产，不继续按旧默写目标扩建。
- 语言是否正确与字形是否需练分开。纸质表现经确认后可形成观察；观看演示不生成 Learning Attempt，也不算改对或掌握。
- 退出某项内容、隐藏旧默写入口或以后更换应用时，历史记录保留。实际隐藏和交互改造另走实现与回归流程，不以改文档冒充已上线。

## 打印与反馈

- 家长确认的孩子版可提交打印；家长参考答案另存，不进入孩子版打印任务。
- 打印绑定固定版本和份数。重复请求复用提交结果；发送结果不确定时先查询已有任务，不能盲目再次提交。打印机队列接受、设备完成和孩子作答是不同状态。
- 离线任务要能查看与取消；过期任务不在恢复后无界补打。无人确认的定时生成/打印不因这个定位调整而自动开启。
- 照片先匹配练习和题号，再生成反馈草稿。确认可分题、分次完成；未确认部分保持未知。只上报错题不等于其余均独立正确。
- 迟交按实际作答时间留存，不覆盖较新证据；重复确认保持幂等。没有照片时，明确的人工结果同样可以确认。
- 正确结果和错误结果均应可保留；不为记录正确作答虚构 Mistake Case。现有 Learning Attempt 的错题归属与纸质正向作答之间，仍需在实现时明确接口和兼容方案。

## 成效与实施次序

先看是否减少了家长准备工作、家人是否能拿纸使用、下次是否知道少练什么。真实错题的订正情况仍有价值；游戏首轮正确率和用时作为补充观察，不以使用天数或闭环数量单独衡量效果。

1. 保证真实材料与已确认错误可区分，核对影响选题的旧记录。
2. 跑通有限材料的选题、固定打印版本和可选部分反馈；不等待游戏使用量或网页默写验收。
3. 独立改造游戏首轮/订正统计与写字示范入口，保持已有事实可追溯。
4. 根据纸质使用结果，再增加资料批处理、结构相似题和跨次表现建议；不预建通用插件或自动掌握引擎。

## 首版验收场景

- 连续两周没有打开应用，仍可从确认材料准备一张纸；上份无反馈时不阻塞。
- 游戏首轮 8/10，重试后全部改对：首轮统计不变，订正另计；暂停恢复不把离开时长计入练习。
- 游戏未作答或只完成部分题，不能标成全对；换日不产生补做欠账。
- 只看笔顺后退出，不产生作答或掌握事实；旧默写与字库历史仍可查。
- 同版打印重试不产生额外份数；家长答案不被打印；打印完成不写学习尝试。
- 只确认练习第 2 题时，其余题保持未知；晚交与重复提交不重复写入或覆盖新事实。

本文调整产品方向和验收范围，不变更部署、数据库 schema、既有历史或通知设置。
